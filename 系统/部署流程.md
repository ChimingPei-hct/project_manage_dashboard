# PMD 部署流程

> 适用范围:单 PDT 实例,内网/外网各一台机器。任何部署变更先改本文档,再动 shell。

---

## 0. 前置约束

- 一个部署实例 = 一个 PDT,数据走独立 data 分支(见 `design/03-代码与数据分离约束.md`)
- main 分支不得携带任何实例数据(`design/*.json` 必须保持空模板)
- 飞书 app 必须先在 https://open.feishu.cn 完成 scope 申请与重定向 URL 配置(清单见 `系统/飞书app申请清单.md`)

---

## 1. 主机要求

| 项 | 最低 |
|----|------|
| OS | Linux x86_64 / macOS |
| Python | 3.10+ |
| Node | 18+(仅构建期需要,生产可移除) |
| 磁盘 | 1 GB(代码 + 数据 + 半年快照) |
| 出网 | 可达 `open.feishu.cn` |

---

## 2. 目录布局

```
/opt/pmd/
├── app/                 # main 分支 clone(代码)
├── data-<pdt>/          # data-<pdt> 分支 worktree(实例数据)
│   └── design/
│       ├── pdt.json
│       ├── ltcs.json
│       ├── modules.json
│       ├── module_status.json
│       ├── module_updates.jsonl
│       ├── config.json
│       └── weekly_snapshots/
└── dist/                # 前端构建产物(由 app/frontend/dist 软链或拷贝)
```

挂载 data 分支:

```bash
cd /opt/pmd/app
git worktree add ../data-<pdt> data-<pdt>
```

---

## 3. 环境变量(systemd EnvironmentFile)

| 变量 | 必填 | 示例 | 说明 |
|------|------|------|------|
| `DATA_DIR` | ✅ | `/opt/pmd/data-luna6/design` | 数据目录绝对路径 |
| `PORT` | | `18080` | 后端监听端口 |
| `DEV_LOGIN` | | `0` | 生产必须 `0`,不写默认 `0` |
| `COOKIE_SECURE` | ✅ HTTPS | `1` | 走 HTTPS 反向代理时必填 |
| `FEISHU_APP_ID` | ✅ | `cli_xxx` | 飞书 app id |
| `FEISHU_APP_SECRET` | ✅ | `xxx` | 飞书 app secret(严禁入仓) |
| `FEISHU_REDIRECT_URI` | ✅ | `https://pmd.example.com/feishu/callback` | 与飞书后台一致 |
| `PMD_DISABLE_SCHEDULER` | | `0` | 关闭定时冻结(仅测试用) |

凭证可放 `/etc/pmd/secrets.env`(权限 600,owner pmd 用户)。

---

## 4. 后端部署

```bash
cd /opt/pmd/app/app/backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 跑自检
PMD_DISABLE_SCHEDULER=1 pytest -v   # 应全绿
```

systemd unit(`/etc/systemd/system/pmd-backend.service`):

```ini
[Unit]
Description=PMD Backend
After=network.target

[Service]
User=pmd
WorkingDirectory=/opt/pmd/app/app/backend
EnvironmentFile=/etc/pmd/secrets.env
Environment="DATA_DIR=/opt/pmd/data-luna6/design"
Environment="PORT=18080"
Environment="COOKIE_SECURE=1"
ExecStart=/opt/pmd/app/app/backend/.venv/bin/uvicorn main:app --host 127.0.0.1 --port 18080
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

---

## 5. 前端部署

```bash
cd /opt/pmd/app/app/frontend
npm install
npm run build           # 产出 dist/
```

由前置 Nginx 直接托管 `dist/`,API 反代到后端:

```nginx
server {
  listen 443 ssl http2;
  server_name pmd.example.com;

  root /opt/pmd/app/app/frontend/dist;
  index index.html;

  location /api/ {
    proxy_pass http://127.0.0.1:18080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
    # SSE 长连接
    proxy_buffering off;
    proxy_read_timeout 1h;
  }

  location /feishu/callback {
    try_files $uri /index.html;
  }

  location / {
    try_files $uri /index.html;
  }
}
```

## 6. 飞书 app 配置核对

部署前在 https://open.feishu.cn 后台核对:

- 重定向 URL = `${FEISHU_REDIRECT_URI}`
- Scope 包含 `contact:user.base:readonly` 等(详 `系统/飞书app申请清单.md`)
- `config.json.tenants` 白名单覆盖本部署对应的 tenant

## 7. 首次启动校验清单

```bash
# 1. 数据完整性
python3 /opt/pmd/app/design/validate_data_files.py   # 校验 schema

# 2. 后端健康
curl -sf http://127.0.0.1:18080/api/auth/me          # 401 = 正常未登录

# 3. 前端可访问
curl -sf https://pmd.example.com/                    # 200

# 4. 真实登录端到端(浏览器手测一次)
#    → 点"飞书登录" → 授权 → 落回 / → 头像 chip 显示自己

# 5. 角色矩阵
bash /opt/pmd/app/scripts/role-test.sh               # 全绿
```

## 8. 升级流程

```bash
cd /opt/pmd/app
git fetch && git checkout main && git pull           # 仅拉代码
cd app/backend && source .venv/bin/activate && pip install -r requirements.txt
cd ../frontend && npm install && npm run build
sudo systemctl restart pmd-backend
sudo systemctl reload nginx
```

**禁忌**:升级时勿在 `/opt/pmd/app` 误切到 data 分支——会让代码目录混入实例数据。

---

## 9. 备份

- `data-<pdt>` 分支每日 `git push origin data-<pdt>`(远端即备份)
- `weekly_snapshots/` 是不可变冻结快照,丢失代价高,务必随 data 分支一起推送
- 飞书 secret 与 `.jwt_secret` 单独备份(后者首启动自动生成于 backend 目录)

---

## 10. 回滚

- 代码回滚:`git checkout <prev-commit>` + 重启
- 数据回滚:在 data 分支用 `git revert <bad-commit>` 或挑选历史 weekly_snapshot 恢复
- 严禁 `git reset --hard` data 分支(会丢实例数据)
